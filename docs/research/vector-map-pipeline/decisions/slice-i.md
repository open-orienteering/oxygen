| 2026-11-17 | I1: the colour-order harness (`scripts/measure-colour-order.mjs`, `packages/api/src/render/colour-order-diff.ts`; `map-rendering.md` §6.5) | **Decided in the row** (planner and session; none changes an interface later rows rely on except as noted). (1) **Changes are named by paint, not by colour**: a second, crisp-edged raster per order with every (row, pass kind, symbol) in its own colour gives the layer on top at each pixel; where both orders have the same layer on top, the pair of layers around the pixel whose order flipped, then the same on paint images with the shared top layer peeled off (up to three deep), then the neighbours' kind, else `(unattributed)`. (2) **`(unattributed)` is never classified**, so it counts against the gate. (3) **Tolerance 16** (§6.2) by default instead of the experiment's 24; at 24, before (9), the tool reproduced the experiment's changed pixels within 0.14 % on all ten maps (puit-de-laven 742, Crop-A, Mörtsjön exactly; Sprint 157 973 against 157 965 — the 5 mm tile margin of (4)). (4) Each tile draws objects within **5 mm** of it (the experiment: bounding boxes meeting the tile). (5) The permutation ranks by the **alignment palette** (`alignmentPalette`, the overlay's rows included), where the experiment used `paletteStack` (the spec's rows only). (6) The **classification is a file** of directional `from` / `to` rules (first match, optional map scope, `*`); suggestions are written beside each run and never counted; exit 1 while anything is unclassified, so the I1 baseline exits 1 by design. (7) Layer names are palette ids (`+`-joined roles, `none:<class>:<kind>`, `#n`, `graphic:`), never the map's colour names, so output and spec can quote them. (8) see the next row. (9) **Proxy-drawn objects keep their colour**: the candidate's proxies (objects whose symbol has no IR, drawn in stack row 0) take the row source row 0 moved to; the experiment recoloured them, which inflated its numbers where such objects exist (Crop-B 23 247 → 2 678 changed pixels — its largest kind, black frame bars turning yellow, was this artefact; the ski-O map 94 009 → 91 175, the Nacka map 267 473 → 260 927). | (1) Naming by exact colour cannot tell rows that share an ink apart — every split colour from I3 on — and named about a third of puit-de-laven's changed pixels; centre-sampled top layers alone left 5–6 % of the club maps' changed pixels unnamed (thin lines over a swap, a sliver of a building's edge over a swapped road outline and paved brown), flipped pairs and peeling bring that to 0.2–2.6 % per map (2.1 % over the ten). (2) The gate must not pass by leaving pixels unnamed. (3) One tolerance across the raster tiers. (5) Roles are palette ids of the alignment palette (`map-symbols.md` §9.3 "Roles"); the ski map's own ski rows have palette places there. (6)–(7) As B9 and C7 did for their sanctioned codes; the corpus stays in `.local/` (AGENTS.md §12). |
