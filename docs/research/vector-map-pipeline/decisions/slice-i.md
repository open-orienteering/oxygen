| 2026-11-17 | I1: the colour-order harness (`scripts/measure-colour-order.mjs`, `packages/api/src/render/colour-order-diff.ts`; `map-rendering.md` §6.5) | **Decided in the row** (planner and session; none changes an interface later rows rely on except as noted).
