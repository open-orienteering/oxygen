Recorded by the coordinator. The split, root causes and defaults are the
plan of a Fable planning agent (user 2026-11-07: "use fable for all
planning"); each row's session still runs `slice-planner` first and may
reopen a default with a reason. Defaults are taken overnight-style and

   replace map. I want all this gone, but all of it and the map scale should
   be in a separate dialogue, accessible via a nice looking map icon."

## Defaults (for user review)

- P4: the ghost circle is drawn only when the layer draws no provisional
  visit (no course selected); the label stays. P1's `placed` flag is
  reverted: *Add control* in `V` shows the dashed ring with the action bar
  again; with `K` armed no ring (D12, an exclusive tool has no action bar).
  The `editor-ghost` E2E anchor moves to the label.
- P5: a pure helper uses the course's `startControlId` / `finishControlId`
  first, nearest-to-first/last-control only as the fallback for legacy
  courses; a finish-only course works the same way. Web-side, no API change.
- P6: a modal dialog (`editor-map-info-dialog`) from a new map icon
  (`editor-map-info`) in the top bar after Export ▾: map name, scale, north
  lines, document info, and the actions Review symbols, Replace map, From
  club library. The scale leaves the course-info popover. Desktop only (the
  phone never had the row); a phone entry in the overflow menu is a possible
  follow-up. Replace map keeps `accept=".ocd"`. The upload / club-picker logic
  moves to a hook shared by MapPanel's drop zone and the dialog.

P4 and P5 may run together; P6 after both (`EditorPage.tsx`, `MapPanel.tsx`).
