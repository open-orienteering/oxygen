# The placement loupe (2026-11-11) and the row F27

Recorded by the coordinator after F24 (#164) and the F7 flake fix (#165)
merged. The row's session runs `slice-planner` first and may reopen a
default here, with a reason.

## The request

"When placing controls originally, I don't get a loupe, that would make
sense to add it there as well." F24 shows the loupe only while a point is
dragged. Placing with the mouse is a click, so nothing shows.

## Answers (user, 2026-11-11)

1. **Not a press-and-hold.** The first proposal was that holding the button
   would show the loupe, moving would adjust the point, and the release would
   place it. The user rejected it: a left drag must **always pan the map**
   while a placing tool is armed (`course-editor.md` §6.1, "Drag pans"),
   without placing anything. A click still places at once.
2. **A toggle instead.** When it is on, the loupe follows the mouse cursor
   while a **placing tool** is armed and the pointer is over the map: `S`,
   `K`, `M`, `X`, `C` (crossing point) and `T` (map text). `V`, the area
   tools (`A`), `G` and Layout mode are unchanged. Drags keep F24's loupe
   whatever the toggle says.
3. **A top-bar button and the key `L`.** The button is a magnifier, lit when
   on. `L` is free today (§6 key table). The setting is remembered between
   sessions.
4. **Touch: the same toggle.** When it is on, the loupe shows above the
   centre crosshair while a placing tool is armed. That covers Field mode and
   the tablet's pin-drop (08 §5.3). It is centred on the point the Place
   button would drop. When the toggle is off, touch placement is unchanged.

## Open for the planner

- The loupe's centre while hovering is the point the click would place: the
  provisional visit's point (snapped, or a reused site's centre), not the
  raw cursor.
- Its placement follows `loupePlacement` with lift 0 (16 px above the
  cursor; below it at the map's top). At the crosshair it follows the same
  rule with the crosshair as the point.
- Where the button goes in the phone's compact bar or overflow, and how it
  is labelled (i18n en + sv).
- The loupe goes when the pointer leaves the map, when the tool is
  disarmed, or when the toggle is turned off. A hover adds one inset render
  per frame (`map-rendering.md` §5.5).
