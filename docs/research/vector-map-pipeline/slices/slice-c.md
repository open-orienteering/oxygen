The full rows of this slice, moved out of [SLICES.md](../SLICES.md) on 2026-11-21. Statuses reported `review` for PRs that merged on 2026-11-20 are corrected; everything else is as it was. New rows for this slice are added here; open rows are also listed in SLICES.md.

Split 2026-10-23 from 09 §4 C, 05 §5–§7 and §9, 08 §4.1 / §4.5 / §4.6
(only `courseLayer()`, `resolveSheet` and the `courses.geometry`
compatibility artifact — the editor is slice D), 04 §7 (course overprint
as objects, the dynamic bucket, UI layers) and 09 §8. Slice B draws the
document; C makes the course *part* of the document's symbolisation —
one `courseLayer()` in shared feeding the viewer, the PDF and the stored
GeoJSON — and gives the shared stage its second backend: `maps.pdf`
without SVG, `rsvg-convert` or the ink raster (05 §3). Build order the
research supports: the two pure shared modules first (course layer C0,
PDF operator layer C1 — disjoint, no dependency on each other), the page
composer C2 joins them, the route switch with the golden PDF tier and
`qpdf` in CI last (C3). Three rows can start at once (C0, C1, C6 —
disjoint areas); C4 (viewer) and C5 (geometry) follow C0 and run in
parallel (web vs api); C2 follows C0 + C1; C3 follows C2 and C6 (both
touch `routes.ts`); C7 and S2 follow C3. The `vector` / `legacy` switch
gates reads only (09 §3): the legacy SVG overlay, `rsvg-convert` and
`fonts-liberation` stay until slice E.

Decided in this split (coordinator, 2026-10-23; a row's planner may
reopen any of them with a reason):

- `courses.geometry`'s automatic cuts come from the pinned document only
  for `vector` events (09 §3 gates reads, and this write's result could
  differ by a rounding); `legacy` events keep the OCAD parse (C5).
- Mapper sources as event/club map *apply* (`event-crs.ts`,
  `map-north.ts` / `map-projection.ts` document branches) is slice E, not
  C.
- Dual-run E2E in C: `course-maps.spec.ts` (the gate's), plus
  `map-control-circles` and `map-multicourse` (small); `course-editor.spec.ts`
  stays single-project until D rewrites the editor.
- Imported `ocd` courses keep their file-authored leg bends and circle
  gaps through an optional per-leg path / per-control gap input to
  `courseLayer()` (cheap; retired when D's `LegProps.path` lands).

Decided by the user 2026-10-23 (on the coordinator's recommendations;
decision log): (1) G1 — C0 writes `course-layer.md`'s derivation,
geometry-rule and GeoJSON-projection sections now; the structure /
concurrency sections wait for G1, which is recorded before slice D;
(2) print profiles (05 §5.5: `cmyk-offset`, ICC, test sheet) are not in
C — C ships `cmyk` + `rgb`, S2 runs `cmyk` only, profiles become their
own row before the default flips; (3) the C-gate's sanctioned
differences are the CMYK colour shift against the RGB legacy PDF and
`colorOverrides` / `northLinesBelow` not applied on the vector path
(as the viewer today), recorded in `course-print.md`.
